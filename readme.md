# catan generator (archived)

This repository is the original Angular 9 implementation, kept read-only as
history. **It is no longer developed or deployed.**

The Catan generator now lives at
**[lukeludlow/catan-next](https://github.com/lukeludlow/catan-next)** and is
deployed at **[catan-next.vercel.app](https://catan-next.vercel.app)** — a
Next.js rewrite where every board is a pure function of its seed, so the URL
itself is the board and any link reproduces it exactly.

[`lukeludlow.github.io/catan`](https://lukeludlow.github.io/catan/) now
redirects there.
